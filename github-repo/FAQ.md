## 安装与启动

### Q: 如何安装 OpenClaw U盘版？

**A:** OpenClaw U盘版无需安装，只需：
1. 下载压缩包并解压到U盘或本地目录
2. 双击运行 `启动器.bat` 或 `U-Claw-Launcher.ps1`
3. 首次运行会自动配置环境

### Q: 启动时提示"无法找到 Node.js"怎么办？

**A:** 这是因为缺少 Node.js 运行时。解决方法：
1. 点击启动器中的"修复环境"按钮
2. 等待自动下载并安装 Node.js
3. 修复完成后重新启动

### Q: 可以在 Mac 或 Linux 上运行吗？

**A:** 当前版本主要支持 Windows 系统。Mac 和 Linux 用户可以：
- 使用虚拟机运行 Windows 版本
- 等待未来的跨平台版本

### Q: 启动时出现乱码怎么办？

**A:** 这是编码问题，解决方法：
1. 确保系统区域设置支持中文
2. 右键点击 PowerShell 脚本 → 属性 → 解除锁定
3. 使用 UTF-8 编码的编辑器打开脚本

## 版本更新

### Q: 如何检查更新？

**A:** OpenClaw 会自动检查更新：
- **自动检查**：启动时自动检测（需要网络）
- **手动检查**：点击"升级 OpenClaw"按钮
- **状态提示**：状态栏显示"发现新版本"提示

### Q: 更新提示"设备未激活"怎么办？

**A:** 自动升级功能需要设备激活：
1. 点击"激活授权"按钮
2. 输入有效的授权码
3. 激活成功后即可升级

### Q: 更新失败如何回滚？

**A:** OpenClaw 会自动备份：
1. 升级前自动创建备份
2. 升级失败时自动回滚
3. 手动回滚：从 `data/backup` 目录恢复

### Q: 如何跳过某个版本更新？

**A:** 在更新提示窗口：
1. 勾选"跳过此版本"
2. 点击"稍后提醒"
3. 该版本将不再提示

## 网络与连接

### Q: 启动时显示"离线模式"怎么办？

**A:** 这是网络连接问题：
1. 检查网络连接是否正常
2. 检查防火墙设置
3. 尝试使用代理或VPN
4. 离线模式下仍可使用本地功能

### Q: 版本检查超时怎么办？

**A:** 可能是网络问题：
1. 检查是否能访问 `github.com`
2. 尝试访问 `cdn.jsdelivr.net`
3. 使用本地版本信息作为备用

### Q: 如何配置代理？

**A:** 设置系统代理：
1. Windows 设置 → 网络 → 代理
2. 配置 HTTP/HTTPS 代理
3. 重启 OpenClaw

### Q: 网络状态显示不准确？

**A:** 刷新网络状态：
1. 点击"升级 OpenClaw"按钮
2. 系统会重新检测网络
3. 状态栏会更新网络状态

## 模型配置

### Q: 如何切换 AI 模型？

**A:** 切换模型步骤：
1. 点击"切换 AI 模型"按钮
2. 从列表中选择目标模型
3. 点击"应用"保存设置

### Q: 支持哪些 AI 模型？

**A:** OpenClaw 支持 85+ 模型：
- **国内模型**：豆包、智谱GLM、通义千问、文心一言等
- **国际模型**：GPT-4、Claude、Gemini、Mistral等
- **本地模型**：Ollama 本地部署模型

### Q: 如何添加自定义模型？

**A:** 添加自定义模型：
1. 点击"切换 AI 模型"
2. 点击"添加自定义模型"
3. 填写模型名称、API地址、密钥等信息
4. 保存后即可使用

### Q: 模型 API Key 如何获取？

**A:** 各平台获取方式：
- **豆包**：访问火山引擎控制台
- **智谱**：访问智谱AI开放平台
- **通义**：访问阿里云百炼平台
- **OpenAI**：访问 OpenAI API 页面

## 授权激活

### Q: 为什么需要激活授权？

**A:** 授权激活用于：
- 解锁自动升级功能
- 防止盗版传播
- 提供技术支持

### Q: 如何获取授权码？

**A:** 获取授权码方式：
1. 访问官方网站购买
2. 参与活动免费获取
3. 联系客服咨询

### Q: 授权码可以用于多台设备吗？

**A:** 授权策略：
- **标准版**：1个授权码绑定1台设备
- **专业版**：1个授权码可绑定3台设备
- **企业版**：支持批量授权

### Q: 授权过期后还能使用吗？

**A:** 授权过期后：
- 基本功能仍可使用
- 自动升级功能将受限
- 需要续费才能解锁完整功能

### Q: 如何查看授权状态？

**A:** 查看授权信息：
1. 点击"激活授权"按钮
2. 查看当前授权状态
3. 显示到期时间和设备信息

## 其他问题

### Q: 如何备份配置和数据？

**A:** 使用备份功能：
1. 点击"一键备份"按钮
2. 选择备份内容（配置/技能/核心文件）
3. 选择备份位置
4. 点击"开始备份"

### Q: 如何恢复备份？

**A:** 恢复备份步骤：
1. 点击"一键备份" → "恢复备份"
2. 选择备份文件
3. 确认恢复操作
4. 重启 OpenClaw

### Q: 技能管理在哪里？

**A:** 管理已安装技能：
1. 点击"技能管理"按钮
2. 查看已安装技能列表
3. 点击技能查看详情
4. 启用/禁用技能

### Q: 如何报告问题或建议？

**A:** 反馈渠道：
1. **GitHub Issues**: 提交 Bug 报告或功能请求
2. **用户群**: 加入用户交流群
3. **邮件**: 发送问题到官方邮箱

### Q: 数据存储在哪里？

**A:** 数据存储位置：
- **配置文件**: `data/.openclaw/`
- **会话记录**: `data/.openclaw/agents/`
- **备份文件**: `data/backup/`
- **日志文件**: `data/.openclaw/logs/`

### Q: 如何完全卸载？

**A:** OpenClaw 是便携式软件：
1. 关闭所有 OpenClaw 进程
2. 删除整个 OpenClaw 目录
3. 清理桌面快捷方式（如果有）
